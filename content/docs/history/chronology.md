## Reading the table correctly

A row with a private hash can be audited against the preserved Git bundle but
not by an arbitrary web visitor. A row with a public link should remain
clickable as long as the upstream/public repository exists. A row labeled
project/oral history is deliberately not represented as stronger evidence than
it is.
