# Starwind: R3mastered

This repository is the project home for **Starwind: R3mastered**, the modern
OpenMW reconstruction and continuation of Starwind's merged-content,
compatibility, asset, and Lua-modernization work.

## Documentation

The site documentation lives under [`content/docs`](content/docs/).

Start with:

- [`content/docs/history`](content/docs/history/) — detailed, source-linked project history;
- [`content/docs/history/chronology.md`](content/docs/history/chronology.md) — dense audit timeline;
- [`content/docs/history/source-ledger.md`](content/docs/history/source-ledger.md) — source/evidence registry.

The historical section deliberately distinguishes public Git evidence, private
primary sources, published mod/issue pages, artifacts, oral history, and later
interpretation.
